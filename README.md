# だるまさんがころんだ（また遊ぼ）

「また遊ぼ」（mataasobo.com）の、みんなで遊ぶだるまさんがころんだ。今は**子ども役で遊ぶ試作**の段階。

## 動かす

`index.html` をブラウザで開くだけ（ビルド不要）。前の試作は `proto-kids.html`（子ども役）と `proto-daruma.html`（だるま役）に残してある。

## 1つにまとめた画面（index.html）　← これから育てるのはこちら

- だるま役も子ども役も同じ画面。`?role=kid`（子ども）・`?role=daruma`（だるま）。最初の画面でも選べる
- 決まりは `rules.js`（`old/daruma-core.js` の上に、今の決まりを足したもの）。だるま役・子ども役・シミュレーターで同じ
  - 子どもの止まり方は人に合わせて、全速から止まるまで 0.4〜0.7 秒（人は 0.5 秒）
  - 人の子どもも元の子どもの1人として同じコースを走る（全速まで 0.33 秒）。CPU の子どもは元の子どもの AI
  - 見送ったら止まらず「だ」から続く。強気度は言っている間に予約、見送りの「だ」かひと休みで変わる
  - 振り向いてから見るまで 0.1 秒（`GRACE_TICKS`）
  - 子ども役のだるまは CPU（`cpuDaruma`：先頭が奥まで来て、まだ動いていたら振り向く。シミュレーターの「人間の読み」と同じ見方）
- だるまの時計は40秒（言っている時間だけ）。だれかがタッチしたら子どもの勝ち
- 見た目は前の子ども役の試作と同じ（地面にだるまが立つ横から見た図）
- 右上の「⏸ 中断」でいつでも止められる。「⚙ 調整」に、中断・やめる・CPU の子の考え（賭け／止まる）を見る・手ざわりの数字（あなたの加速と減速、CPU の子の止まり方、見逃し、時計、ひと休み、合図）

## 前の子ども役の試作（proto-kids.html）

- あなたは子ども。だるま（CPU）が「だるまさんがころんだ」と言っている間だけ進める。振り向いたときに動いていたら、35下がる（`KNOCK`）。だるまにタッチしたら勝ち
- 操作は3つから選べる：A 押しっぱなしで走る（離すと少しすべる）・B 連打で1歩ずつ・C 引くほど速い。けんじさんの感想は「押しっぱなしが自然」
- だるまの言い方は毎回変わる（ふつう・ゆっくり・はやい・ためて一気・途中でためる）
- **見送り**：振り向かないときは止まらず、最後の「だ」が次の「だ」を兼ねてそのまま言い続ける（子どもは走り続けられる）。強気度は、言っている間はいつでも次のぶんを予約でき、この「だ」で変わる（ひと休み中はすぐ変わる）
- **強気度**（低〜激）：だるまのうしろの光の色・大きさ・脈の速さと文字で見える。強気なほど見送りやすい
- **気力**：だるまの下のゲージ。見送るとたまり、振り向くと使う（どちらも強気度が高いほど大きい）。黒い線より少ないと振り向けない
- 振り向いて見終わったら**ひと休み**（1〜3.5秒、子どもは動けない）。言い始める0.8秒前に「すぅ…」と合図
- CPU の子どもが2人（せっかち・まじめ）。強気度と気力を見て、欲ばったり止まったりする

調整用の数字は、ファイルの上のほうにまとめてある（`A` `B` `C` `GRACE` `KNOCK` `LV` `BREAK_MIN/MAX` `CUE`）。

## 前のだるま役の試作（proto-daruma.html）

- 見送ったときは、子ども役と同じく止まらずに「だ」から続ける。強気度は、言っている間に押すと「予約」（点線の枠）になり、見送りの「だ」かひと休みで変わる。ひと休み中はすぐ変わる。振り向く／見送るの選びは前のまま
- 元のだるま（old/）は見送るたびに時間が止まっていた。old のシミュレーターはその決まりのままなので、バランスは測り直しがいる

## 考え中（2026-10-18）

- **だるま側と子ども側で遊び方がちがう**のが、このゲームの面白さ。だるまは気力をやりくりしてテンポと強気度で揺さぶる「読ませる側」、子どもは光と気力を見てどこまで攻めるか決める「読む側」。1人対みんなで、役を交代しながら遊ぶ形（Dead by Daylight や人狼のような）
- **CPU のだるま（子ども役のとき）のテンポ**：今は言い始める前に5つの言い方からくじ引きするだけ。元のだるまのように、言っている途中で子どもの様子を見てテンポを上げる（上げると気力を使う）かどうかは、もう少し考える
- **だるま役の分かりにくさ**（前の proto-daruma.html で）：振り向いた瞬間に誰が捕まったか、子どもが何を考えているか、操作が4つあること、テンポの体感

## これから

- だるまの勝ち条件：元のだるま（old/）と同じく「言っている間だけ進む時計（40秒）」が候補。休憩・振り向きは時計に入れない
- みんなで遊ぶ版：だるま1人（人）＋子ども（人と CPU）。部屋のしくみは okashi-narabe のサーバー（api.mataasobo.com）を使い回す。通信の遅れで「止まったのにアウト」にならない工夫がいる
- 捕まった子のアイテム応援、ひと休み中のサプリ（案）
- アイデアの経緯は okashi-narabe の docs/ideas.md の「だるまさんがころんだ」の節

## old/

前に作った「だるま役で遊ぶ」版（2026年8月、別のリポジトリだったもの）を写してある。元絵（sozai/、24MB）は入れていない。

- `daruma-core.js`：ゲームの決まりと、作りこんだ子どもの AI（1周7つの判断・体・気質・動機・だるまの読み）
- `daruma-sim.js`：だるまの作戦ごとの勝率を測るシミュレーター（`node old/daruma-sim.js`）
- `daruma-game.html`：だるま役で遊ぶ画面。`daruma-balance-lab.html`：数字を調整するラボ
- `README.md`：考え方（勝ち条件を回数ではなく時計にした理由、数値ひとつで決まる設計にしない、など）
- `assets/`・`tools/`：切り出した画像と、それを作るスクリプト

2026-10-17 に old のシミュレーターでテンポを固定して回すと、人間の読みのだるまの勝率はテンポ50〜60で山（85%）、速すぎると気力が尽きて6%、一度も振り向かないは全テンポで3〜11%だった（速く言うほど得、にはなっていない）。
